# The ```.gitignore``` file

## What is it?
A ```.gitignore``` file is useful to point which files and folders of a project should not be trackd by Git, be put in the staging 
or pushed on remote repositories. 
A local ```.gitignore``` file is placed in the root directory of a project. It can also be global and any entries in it 
will be ignored in all of the Git repositories.
